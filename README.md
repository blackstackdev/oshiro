# ōshiro website preview

Informational website for ōshiro, an offline Sudoku game with automatic castle growth from Krēˈādiv Worx.

Website preview version 0.1.1. Game candidate version 0.44.0.

This repository contains website pages, a local support-note download tool and selected illustration assets. It does not contain the game engine, Android packages, player saves, credentials or internal project documents.

The privacy notice is explicitly a draft. Operator/contact and final support/privacy disclosures remain pending; there is no live support mailbox or ticket sender yet. This preview is not an AppGallery release or a final effective game privacy notice.

The site code has no analytics or tracking cookies. GitHub Pages logs visitor IP addresses for security; see the Privacy page and GitHub’s privacy statement. The support-note form creates a text file locally and sends nothing.
